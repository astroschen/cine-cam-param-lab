# 开发路线图与验收标准

---

## 1. 里程碑总览

| 阶段 | 目标 | 产出 | 预估 |
|---|---|---|---|
| **M0 地基** | 工程可运行 | Vite + Vue3 + TS 脚手架、设计令牌、布局骨架 | 1 天 |
| **M1 参数引擎** | 参数能驱动一切 | schema、store、URL 编解码、uniform 映射 | 2 天 |
| **M2 视觉模拟** | 预览能看出变化 | WebGL 管线 5 个 pass、Before/After | 4 天 |
| **M3 提示词输出** | 能复制就用 | 编译核心 + 5 平台渲染器 + 负面词 | 3 天 |
| **M4 打磨** | 好用 | 预设库、撤销重做、词条溯源、无障碍 | 3 天 |
| **M5 交付** | 能发布 | 构建配置、SEO、部署、PWA | 1 天 |

**合计约 14 个工作日**（单人全职）。

---

## 2. 分阶段详细计划

### M0 · 地基（1 天）

**任务**

- [ ] 初始化 Vite + Vue 3 + TypeScript 项目
- [ ] 建立 `styles/tokens.css`（全部设计令牌）与 `base.css`
- [ ] 搭建三栏布局骨架 + 响应式断点
- [ ] 建立 `types/` 下的 TS 类型定义
- [ ] 路由：仅单页，无需 router

**验收**

- `npm run dev` 启动，三栏布局在 1440px / 1024px / 375px 三档下布局正确
- 所有颜色、间距、字号来自 CSS 变量，无硬编码
- `npm run build` 通过，无 TS 报错

---

### M1 · 参数引擎（2 天）

**任务**

- [ ] `schema/params.ts` 实现全部 52 个参数（按 02 文档）
- [ ] `schema/tokens.ts` 建立 token 词库
- [ ] `schema/looks.ts` 16 种 Look 的曲线参数
- [ ] `stores/params.ts`：扁平键状态、历史栈、预设应用
- [ ] `utils/urlState.ts`：参数 ↔ URL hash 编解码（带 base64url + 可选 deflate）
- [ ] `composables/useUniforms.ts`：参数 → uniform 对象
- [ ] 基础滑块/下拉/开关/颜色/标签组件

**验收**

- 每改一个参数，URL 同步更新，刷新后完整还原
- 预设应用正确覆盖对应键，不影响其他键
- 撤销/重做 ≥ 50 步正常
- `uniforms` 计算耗时 < 1ms

---

### M2 · 视觉模拟（4 天）

**任务**

- [ ] `engine/renderer.ts`：WebGL2 上下文、FBO 管理、resize、rAF 调度
- [ ] Pass 0：景深近似 + 焦外形态 + 变形宽银幕椭圆
- [ ] Pass 1：曝光 / 白平衡 / Look / 对比度 / 色阶 / 滚降 / 暗部 / 饱和 / 分离色调 / 锐化
- [ ] Pass 2：分离高斯模糊 → 泛光 + 光晕
- [ ] Pass 3：色差 / 暗角 / 镜头光斑
- [ ] Pass 4：胶片颗粒 / 数码噪点
- [ ] 参考图导入（拖拽 / 点击 / 粘贴），尺寸限制与降采样
- [ ] 内置 4 个程序化测试场景
- [ ] Before/After 对比分割（拖动 + 键盘）
- [ ] HUD 读数条
- [ ] 渲染分辨率自适应（拖动 0.75×，停止 1.0×）

**验收**

- 1080p 参考图下拖动滑块稳定 60fps
- 光圈/焦距/白平衡/饱和度/颗粒的变化在画面上肉眼可辨
- 对比分割可用鼠标与键盘操作
- 颗粒在暗部更明显、高光更弱（视觉确认）
- 泛光与光晕颜色区分正确（泛光偏白，光晕偏红橙）

## 3. MVP 范围裁剪建议

若时间紧，**M2 的景深近似（Pass 0）与光晕**可以延后。理由：

- 景深是最难模拟准确的，且效果在提示词里用文字描述同样有效
- 光晕（halation）可先用简单泛光代替

**最小可用版本（MVP）= M0 + M1 + M2 的 Pass 1/2/4 + M3 + M4 的预设与溯源**

## 5. 关键风险与应对

| 风险 | 触发条件 | 应对 |
|---|---|---|
| 预览效果与 AI 出图不符 | 用户预期错位 | UI 明示「感知模拟」；保真度徽章；文档说明 |
| 提示词太长导致模型降质 | 52 个参数全开 | 详略级别默认「标准」；提供精简模式；token 按 strength 剪枝 |
| 交互元素过多显得杂乱 | 8 组 52 参数 | 默认折叠非核心组；分组标题带摘要；预设一键起步 |
| WebGL 兼容问题 | 老设备/禁用 GPU | WebGL1 回退；关闭特效时提供「仅提示词」模式（无渲染） |
| 平台语法过期 | 平台更新 | 模板外置 JSON；提供「自定义平台模板」入口让用户自行更新 |
| 移动端 GPU 性能不足 | 低端手机 | 移动端默认 0.5× 渲染分辨率 + 减少 pass |

## 7. 开发顺序建议（关键路径）

```
M0 脚手架
  └─▶ M1 参数 schema + store
        ├─▶ M3.1 编译核心（不依赖渲染，可并行）
        │     └─▶ M3.2 平台渲染器（可并行）
        │           └─▶ M3.3 提示词 UI
        └─▶ M2 渲染管线
              └─▶ M2.6 Before/After + HUD
                    └─▶ M4 打磨
                          └─▶ M5 部署
```

**并行建议**：M1 完成后，渲染管线（M2）与提示词引擎（M3）可由两人并行，或一人交替推进。提示词引擎不依赖 WebGL，是风险最低的先行模块。
